2

The sky

What the telescope is meant to be looking at. These are the real astronomical signals — the things an interference-removal algorithm must leave intact.

Point sources

Each source is a point on the sky. The dirty image on the Results tab should show a peak where you put it.

No sources — the image will show noise only.

Spectral lines

A narrow emission line, added to every antenna. It is celestial signal, not interference: it is labelled that way in the ground truth, so an algorithm that flags it is being scored as wrong.

No spectral lines in this run.

The interference

Human-made transmitters that reach the antennas. Tick the kinds you want and the simulator records exactly which time–frequency cells they touched — that record is the ground truth an excision algorithm gets scored against.

The instrument

Until you open this, the simulator is an ideal instrument: identical antennas, perfect calibration, no digitisation loss. Everything in here makes it worse on purpose, in the ways real telescopes are worse.
